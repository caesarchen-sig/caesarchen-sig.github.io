# 星屿 · caesarchen-sig 的小宇宙

中文二次元主题个人主页，海边暮色、樱花与星空。

**访问主页：[https://caesarchen-sig.github.io](https://caesarchen-sig.github.io)**

## 页面功能

- 个人介绍、项目展示、兴趣与 GitHub 入口
- 手机 / 平板 / 桌面响应式布局
- 深浅色切换，保存在浏览器本地
- 樱花飘落动效，遵循系统“减少动态效果”偏好
- 可收起的手机导航、用户名复制
- 无需安装依赖，无广告，无访问统计

## 修改内容

编辑 `index.html` 中的中文文字、项目链接即可。样式和脚本都在同一文件内。

背景：`twilight.webp`；浏览器图标：`favicon.svg`。

GitHub Pages 使用 `main` 分支的根目录发布。提交后由 GitHub 自动更新。

## 视觉素材

背景由 OpenAI 内置图像生成工具为本项目生成，使用的描述：原创日式动画风格，蓝调时刻的海边铁路远眺，星空、淡紫暮色、樱花与远处灯光；右侧一名背对观众的原创旅行者，左侧保留留白用于标题，无文字及水印。使用 WebP 格式压缩以改善加载速度。

RomM 为上游开源项目，项目卡片链接至个人 Fork，不代表 RomM 由本站作者原创。
